# Clyde

Windows desktop app. This repository is the download feed, not the source code.

## Install (first time)

1. Open the **[latest release](https://github.com/JamesMoffitt/Clyde-Releases/releases/latest)**.
2. Download **`clyde-*-setup.exe`** (for example `clyde-1.3.3-setup.exe`).
3. Run that installer.

Ignore **`latest.yml`** and **`*.blockmap`**. Those files are only for automatic updates after Clyde is already installed.

You need a Windows PC. Sign in with the account you were given — the app has no Sign up.

## Already installed?

Open Clyde and sign in. Updates download from this feed; you do not need a new installer unless you are setting up a new machine.
